# 棚卸しチェック表

毎月の消耗品・事務用品などの棚卸しを記録するシンプルな Web アプリです。
サーバー不要で、`index.html` をブラウザで開くだけで使えます。

## 使い方

1. `index.html` をブラウザで開く
2. 「対象月」を選び、各品目の **今月数量** を入力（＋／− ボタンでも増減可能）
3. 数えたら **確認** にチェック → 上部の進捗バーで残りを確認
4. 「編集」から保管場所・単位・最低在庫数を設定（最低在庫数を下回ると「要補充」表示）

- 前月列には、対象月より前で最後に記録した数量が表示され、増減が自動計算されます
- 保管場所・カテゴリで絞り込み、品名で検索ができます
- 「CSV出力」で対象月の一覧を Excel で開ける CSV として保存できます
- 「印刷」で紙のチェック表として出力できます

## データの保存について

データはブラウザの localStorage に保存されます（端末・ブラウザごとに別管理）。
ブラウザのデータ削除で消えるため、定期的に「バックアップ保存」で JSON を保存してください。
「バックアップ復元」で別の端末へ移すこともできます。

## 初期登録品目

`js/seed.js` に記載された品目が、初回起動時に登録されます。

| 品名 | カテゴリ | 単位 |
| --- | --- | --- |
| ティッシュペーパー | 消耗品 | 箱 |
| トイレットペーパー | 消耗品 | ロール |
| 紙コップ | 消耗品 | 個 |

## ファイル構成

```
index.html      画面
css/style.css   スタイル（スマホ表示・印刷対応）
js/seed.js      初期品目
js/app.js       アプリ本体
```
