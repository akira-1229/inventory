# 棚卸しチェック表

職場の外付けハードディスクにある **品目一覧のエクセル** を読み込み、毎月の数量を記録する Web アプリです。
サーバーやインストールは不要で、`index.html` を Edge / Chrome で開くだけで使えます。

- 品目（名称・メーカー・型番・用途・場所・詳細・購入店・写真）は **エクセルが元データ**。アプリからは書き換えません
- 数量・確認チェック・メモ・単位・最低在庫数は **アプリ側** に記録します
- 火曜日にパソコンを起動すると、アプリが自動で開いて最新のエクセルを読み込みます

公開URL: https://akira-1229.github.io/inventory/

## はじめての設定（職場のPCで1回だけ）

1. `js/config.js` の `excelFileName` にエクセルのファイル名を書く
   （空欄のままでも、フォルダ内のエクセルが1つだけならそれを読みます）
2. **Edge** で https://akira-1229.github.io/inventory/ を開き、「フォルダを登録」→ 外付けハードディスクのエクセルが入っているフォルダを選ぶ
3. このリポジトリの `tools/install-tuesday-startup.bat` を職場のPCにダウンロードしてダブルクリック
   → 火曜日にWindowsへサインインした時点で、Edge でアプリが開くようになります（管理者権限は不要）
   - 解除する場合: `tools/uninstall-tuesday-startup.bat`

## 火曜日の流れ

1. パソコンを起動（サインイン）すると、Edge でアプリが開く
2. 最新のエクセルを自動で読み込む
   - 外付けハードディスクの準備ができていなければ、10秒おきに約2分間再試行します
   - ブラウザの許可が切れている場合は右上の「更新」を押して「許可」。
     Edge で「サイトにアクセスするたびに許可」を選ぶと、次回からはボタンも不要になります
3. 「○件を読み込みました（追加 ○件・エクセルから削除 ○件）」と表示されれば完了

火曜日以外でも、右上の「更新」を押せばいつでもエクセルを読み込み直せます。
火曜日にパソコンを起動しなかった場合でも、アプリを開くと上部の枠がオレンジになり「火曜日のエクセル確認がまだです」と表示されます。

## 棚卸しのしかた

1. 「対象月」を選び、各品目の **今月数量** を入力（＋／− ボタンでも可。空欄で押すと前月の数量から増減）
2. 数えたら **確認** にチェック → 上部の進捗バーで残りを確認
3. 品目名か「詳細」を押すと、エクセルの内容と写真が見られます。ここで次の設定ができます
   - **単位**（箱・袋など）
   - **最低在庫数**: 下回ると「要補充」と表示
   - **棚卸しの対象外**: 給茶機・自動販売機など数えない品目を一覧から外す（「対象外も表示」で再表示）

エクセルから品目が消えた場合、記録が残っている品目は「エクセルに無し」として残ります（不要なら詳細画面から削除）。
品目はエクセルの **名称** で照合するため、名称を変えると別の品目として扱われます。

## データの保存について

- 数量などの記録はブラウザ内（localStorage）に保存されます。PC・ブラウザごとに別管理です
- ブラウザのデータを削除すると消えるため、定期的に「バックアップ保存」で JSON を保存してください
- 「CSV出力」で対象月の一覧を Excel で開ける CSV として保存できます

## 設定（js/config.js）

| 項目 | 内容 |
| --- | --- |
| `excelFileName` | 読み込むエクセルのファイル名 |
| `sheetName` | シート名（空欄なら先頭のシート） |
| `excelFolderName` | エクセルのフォルダ名。登録時に違うフォルダを選ぶと確認が出ます |
| `checkWeekday` | エクセルを確認する曜日（2 = 火曜） |
| `columns` | エクセルの見出し名（1行目）との対応 |

## ファイル構成

```
index.html                     画面
css/style.css                  スタイル（スマホ表示・印刷対応）
js/config.js                   設定
js/xlsx-reader.js              エクセル（.xlsx）読み取り（セル内の写真にも対応）
js/app.js                      アプリ本体
tools/install-tuesday-startup.bat    火曜日の起動時にアプリを開く設定を追加
tools/uninstall-tuesday-startup.bat  上記の設定を解除
```
